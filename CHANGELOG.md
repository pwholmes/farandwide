1.1.0
-----
- Made Far And Away dialogs non-pausing by default in single-player mode.  This behavior can be toggled in the NeoForge Mod Options screen.  The Route Management screen has a 3-second refresh, so in non-pause mode you can track the progress of Vehicles in real time as they progress from one Waypoint to the next.
- Added the "Death Route" feature.  When a player dies a "{Player Name}'s Death Route" is automatically added with a single Waypoint at the location of their death.
- Automatically scroll to a newly created Route in the Route Manager if it was created from that screen.
